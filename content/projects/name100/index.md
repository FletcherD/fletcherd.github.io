A static web game backed by a small Rust lookup server. The server holds an index of every person with a Wikipedia article, built from a Wikidata dump, and matches guesses by name, alias, Wikipedia redirect, or a one-letter typo. Besides women, it can run a game for any of about 7,800 categories.
